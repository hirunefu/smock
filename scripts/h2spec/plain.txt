# The cases of h2spec 2.6.0 that do not pass against smock's plain port
# (h2c), each with its reason. scripts/check-h2spec.sh runs every case of
# h2spec's three sections, and scripts/h2spec-verdict.py judges the run
# against this list. A line gives the case, why it is listed, and the
# reason:
#
#   skipped   h2spec skips the case.
#   left-out  the case runs, but its outcome does not count.
#   #<issue>  the case fails until that issue is done.
#
# A case that fails or is skipped without being listed so fails the run.
# A listed case that passes is reported, so that it can come off. Before a
# branch merges into main, no case waits for an issue here
# (docs/merging-into-main.md).

http2/3.5/2    left-out  On the plain port, octets that are not the HTTP/2 preface start HTTP/1.1 (#133, decision 3), so smock answers h2spec's invalid preface with an HTTP/1.1 400 and closes the connection. h2spec wants GOAWAY PROTOCOL_ERROR or a bare close, and reads the 400 as a broken frame (unexpected EOF). The TLS port, where ALPN h2 starts HTTP/2, passes it (tls.txt).
