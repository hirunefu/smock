# The files that decide a verdict: of the four ledgers, of the merge and
# release checks that read them, of the checks of the keep list and of the
# ledgers, and of the suites that run against a list of cases that may
# fail, with the scripts that install or build those suites' tools, and
# the tests of the scripts listed here (CONTRIBUTING.md, "The weakening
# report"). On each push to a branch other than main, the weakening report
# (scripts/weakening-report.py) lists every change to them, for the
# maintainer to read before merging the branch.
#
# A line is a path, spaces, and what the file is. A path that ends in /
# names every file under that directory, and a * stands for any text
# without a /. The first line whose path names a file says what it is. A
# change to a path that the base's list or the head's names is listed, and
# so is any change to this list.
#
# A change that adds a file that decides a verdict puts it at a path named
# here, or adds its path here, in the same change. Most of these files do
# not exist yet: the issue named in a line creates them. The tests of the
# weakening report (scripts/test-weakening-report.sh) fail when this list
# leaves out a script that a workflow's verdict step runs: a step that
# judges a suite's results against its list of cases, or that tests that
# judgment, or that checks the keep list or the ledgers, and the scripts
# such a step runs, through the scripts it runs. They fail too when it
# leaves out a script of a step that installs or builds a verdict step's
# tool, such as h2spec's install, or the own test of a script it names:
# the script beside it named test-<name>.sh or test_<name>.py, <name> being
# the script's name without its extension, or the test that their table
# names for a script whose test is named otherwise.
